# Novolis.WorkflowEngine.Abstractions

Stable contracts for workflow triggers, steps, sinks, middleware, execution
contexts, and results.

Use this package when an integration only needs to implement a workflow
component. Use `Novolis.WorkflowEngine` to register and execute workflows.
